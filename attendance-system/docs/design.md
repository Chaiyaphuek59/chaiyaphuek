# System Design & Rationale

## 1. การคำนวณระยะทางพิกัด (Haversine Formula)
เนื่องจากพิกัดตำแหน่งได้มาจาก GPS ของอุปกรณ์มือถือ การคำนวณระยะทางบนผิวโลกทรงกลมใช้สูตร:

$$a = \sin^2\left(\frac{\Delta\phi}{2}\right) + \cos(\phi_1)\cos(\phi_2)\sin^2\left(\frac{\Delta\lambda}{2}\right)$$
$$c = 2 \cdot \text{atan2}\left(\sqrt{a}, \sqrt{1-a}\right)$$
$$d = R \cdot c$$

- โดย $R = 6,371,000$ เมตร (รัศมีเฉลี่ยของโลก)
- หาก $d \le 50.0$ เมตร ถือว่าอยู่ในเกณฑ์

## 2. ความปลอดภัยและความเป็นส่วนตัวของข้อมูลใบหน้า
- ระบบจะไม่จัดเก็บภาพถ่ายใบหน้าจริงลงในฐานข้อมูล
- เมื่อถ่ายภาพ ระบบประมวลผลสกัด Feature Vector ขนาด 128 มิติ (Embedding Vector)
- จัดเก็บข้อมูลเวกเตอร์แบบเข้ารหัสในคอลัมน์ `face_embedding`
- การเปรียบเทียบใช้ Euclidean Distance ระหว่างเวกเตอร์: หากค่าน้อยกว่า Threshold (เช่น 0.6) ถือเป็นบุคคลเดียวกัน

## 3. กลไกการตรวจสอบย้อนหลัง (Auditability)
- ทุกการแก้ไขผลเช็กชื่อโดยอาจารย์จะต้องบันทึก ID ของผู้แก้, เวลาที่แก้, และเหตุผลเสมอ เพื่อป้องกันการทุจริต
