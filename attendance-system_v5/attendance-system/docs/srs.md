# ความต้องการของระบบเช็กชื่อ

## 1. ระบบนี้ทำอะไร

โปรเจกต์นี้เป็นเว็บสำหรับเช็กชื่อเข้าเรียน นักศึกษาจะเข้าชั้นเรียนด้วยรหัสวิชา แล้วกดเช็กชื่อเมื่ออาจารย์เปิดรอบไว้

ตอนเช็กชื่อ ระบบจะตรวจสอบ 3 อย่างก่อนบันทึกชื่อ

1. รอบเช็กชื่อยังเปิดอยู่และยังไม่หมดเวลา
2. ตำแหน่งของนักศึกษาอยู่ไม่เกิน 50 เมตรจากตำแหน่งที่อาจารย์ใช้เปิดรอบ
3. เวกเตอร์ใบหน้าที่ส่งมามีความใกล้เคียงกับข้อมูลที่นักศึกษาลงทะเบียนไว้

> หมายเหตุ: ส่วนตรวจใบหน้าในโปรเจกต์นี้เป็นการจำลองด้วยตัวเลขเวกเตอร์ ยังไม่ได้ใช้โมเดล Face Recognition จริง

## 2. ผู้ใช้งาน

### นักศึกษา
- ลงทะเบียนด้วยรหัสนักศึกษา ชื่อ และข้อมูลใบหน้าแบบเวกเตอร์
- เข้าร่วมชั้นเรียนด้วยรหัสวิชา
- ดูสถานะรอบเช็กชื่อ
- เช็กชื่อโดยส่งตำแหน่ง GPS และเวกเตอร์ใบหน้า
- ดูผลว่าการเช็กชื่อสำเร็จหรือไม่

### อาจารย์
- เข้าสู่ระบบด้วยรหัสอาจารย์
- สร้างชั้นเรียน
- เปิดและปิดรอบเช็กชื่อ
- ตอนเปิดรอบ ระบบจะเก็บตำแหน่งของอาจารย์ไว้เป็นจุดอ้างอิง
- ดูรายชื่อนักศึกษาที่เช็กชื่อแล้ว

### ผู้ดูแลระบบ
- เข้าสู่ระบบด้วยรหัสผู้ดูแล
- เพิ่มรหัสอาจารย์
- ถอนสิทธิ์อาจารย์ที่มีอยู่ในระบบ

## 3. เงื่อนไขการเช็กชื่อ

### เวลา
ถ้ารอบถูกปิดหรือหมดเวลา นักศึกษาจะเช็กชื่อไม่ได้

### ตำแหน่ง
ระบบใช้สูตร Haversine คำนวณระยะห่างระหว่างพิกัดอาจารย์กับนักศึกษา และกำหนดระยะสูงสุดไว้ที่ 50 เมตร

### ใบหน้า
ระบบนำเวกเตอร์ที่ลงทะเบียนไว้มาเทียบกับเวกเตอร์ที่ส่งมาตอนเช็กชื่อด้วย Euclidean Distance ถ้าค่าที่ได้ไม่เกิน 0.6 จะถือว่าผ่าน

## 4. ข้อจำกัดของโปรเจกต์

- ข้อมูลหลักของระบบเก็บไว้ในหน่วยความจำ จึงหายเมื่อปิดหรือรีสตาร์ตโปรแกรม
- การตรวจใบหน้าเป็นเพียงตัวอย่างเพื่อให้เห็นขั้นตอนของระบบ ยังไม่ใช่ Face Recognition จริง
- ระบบยังไม่ได้ทำระบบยืนยันตัวตนหรือการเข้ารหัสระดับที่เหมาะกับการใช้งานจริง
- GPS และกล้องขึ้นอยู่กับสิทธิ์ที่ผู้ใช้อนุญาตในเบราว์เซอร์
