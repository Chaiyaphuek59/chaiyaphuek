# ระบบเช็กชื่อเข้าเรียน

โปรเจกต์เว็บสำหรับทดลองทำระบบเช็กชื่อเข้าเรียน โดยใช้อาจารย์เปิดรอบเช็กชื่อ แล้วให้นักศึกษาเช็กชื่อผ่านเว็บ ระบบทดลองตรวจสอบ 3 อย่าง คือเวลา ตำแหน่ง GPS และข้อมูลใบหน้าแบบ vector

โปรเจกต์นี้จัดทำเพื่อการเรียนและการทดลอง ไม่ใช่ระบบ production

## เทคโนโลยีที่ใช้

- Python
- FastAPI
- Jinja2
- HTML / CSS / JavaScript
- Tailwind CSS และ Lucide ผ่าน CDN

## วิธีติดตั้ง

สร้าง virtual environment ก่อน

```bash
python -m venv venv
```

Windows:

```bash
venv\Scripts\activate
```

ติดตั้ง package

```bash
pip install -r requirements.txt
```

## รันระบบ

```bash
uvicorn src.app:app --reload --port 8000
```

แล้วเปิด

```text
http://localhost:8000
```

ถ้าต้องการเข้าหน้าโดยตรง:

- นักศึกษา: `/student`
- อาจารย์: `/teacher`
- ผู้ดูแล: `/admin`
- API docs: `/docs`

## บัญชีตัวอย่าง

- อาจารย์: `T001`
- ผู้ดูแล: `ADMIN-2026` (ถ้าไม่ได้ตั้ง `ADMIN_CODE`)
- ห้องเรียนตัวอย่าง: `MATH101`

## การทดสอบ

ทดสอบส่วนตรวจสอบการเช็กชื่อด้วย

```bash
python -m unittest tests/test_attendance.py
```

มีกรณีทดสอบหลัก ๆ เช่น ผ่านครบ, อยู่นอกระยะ, ใบหน้าไม่ตรง และหมดเวลา

## หมายเหตุเกี่ยวกับ GPS และกล้อง

เบราว์เซอร์ต้องได้รับอนุญาตให้ใช้ GPS และกล้อง โดยทั่วไปควรเปิดผ่าน `localhost` หรือ HTTPS

## ข้อจำกัดของโปรเจกต์

- ข้อมูลปัจจุบันเก็บในหน่วยความจำและจะหายเมื่อรีสตาร์ต
- face vector เป็นการจำลอง ไม่ใช่ Face Recognition model จริง
- ระบบ login และสิทธิ์ผู้ใช้ทำไว้ในระดับที่เหมาะกับการสาธิต
- ยังไม่ควรนำไปใช้เป็นระบบเช็กชื่อจริงโดยไม่เพิ่มฐานข้อมูลและระบบความปลอดภัยที่เหมาะสม
