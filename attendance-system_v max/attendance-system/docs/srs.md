# ความต้องการของระบบเช็กชื่อเข้าเรียน

## 1. ที่มาของโปรเจกต์

โปรเจกต์นี้ทำขึ้นเพื่อทดลองสร้างเว็บสำหรับเช็กชื่อเข้าเรียน โดยให้อาจารย์เปิดรอบเช็กชื่อจากหน้าชั้นเรียน แล้วให้นักศึกษาเข้ามาเช็กชื่อด้วยข้อมูลจากเครื่องของตัวเอง

แนวคิดหลักคือไม่ต้องการให้ใช้แค่ปุ่มเช็กชื่ออย่างเดียว จึงลองเพิ่มการตรวจสอบ 3 อย่าง คือ **เวลา, ตำแหน่ง GPS และข้อมูลใบหน้าแบบ vector**

> หมายเหตุ: เวอร์ชันนี้เป็นโปรเจกต์สำหรับเรียนและสาธิต ยังไม่ได้ใช้ระบบรู้จำใบหน้าแบบ AI จริง และข้อมูลหลักของระบบเก็บไว้ในหน่วยความจำ

## 2. ผู้ใช้งานระบบ

### 2.1 นักศึกษา
- ลงทะเบียนด้วยรหัสนักศึกษา ชื่อ และข้อมูลใบหน้าจากกล้อง
- เข้าสู่ระบบด้วยรหัสนักศึกษาและข้อมูลใบหน้า
- เข้าร่วมชั้นเรียนด้วยรหัสห้องเรียน
- ดูรอบเช็กชื่อที่อาจารย์เปิดอยู่
- เช็กชื่อโดยส่งตำแหน่ง GPS และข้อมูลใบหน้า
- ดูประวัติการเข้าเรียนของตัวเอง

### 2.2 อาจารย์
- เข้าสู่ระบบด้วยรหัสอาจารย์
- สร้างชั้นเรียน
- ดูสมาชิกในชั้นเรียน
- เปิดและปิดรอบเช็กชื่อ
- ใช้ตำแหน่ง GPS ของอาจารย์เป็นจุดอ้างอิง
- ดูรายชื่อนักศึกษาที่เช็กชื่อแล้ว

### 2.3 ผู้ดูแลระบบ
- เข้าสู่ระบบด้วยรหัสผู้ดูแล
- เพิ่มรหัสอาจารย์
- ถอนสิทธิ์อาจารย์
- ดูจำนวนข้อมูลพื้นฐานของระบบ

## 3. เงื่อนไขการเช็กชื่อ

เมื่อกดเช็กชื่อ ระบบจะตรวจสอบตามลำดับดังนี้

1. **เวลา** — ต้องมีรอบเช็กชื่อที่ยังเปิดอยู่และยังไม่หมดเวลา
2. **GPS** — ระยะระหว่างตำแหน่งอาจารย์กับนักศึกษาต้องไม่เกิน 50 เมตร
3. **ใบหน้า** — เปรียบเทียบ vector ที่ลงทะเบียนไว้กับ vector ที่ได้จากกล้อง โดยใช้ Euclidean Distance

ถ้าผ่านทั้ง 3 ข้อ ระบบจะบันทึกการเข้าเรียน

## 4. ข้อกำหนดเบื้องต้น

- ใช้ Python และ FastAPI สำหรับฝั่งเซิร์ฟเวอร์
- ใช้ HTML, CSS และ JavaScript สำหรับหน้าเว็บ
- เว็บต้องได้รับอนุญาตให้ใช้กล้องและตำแหน่ง GPS
- ปัจจุบันข้อมูลเก็บในหน่วยความจำ ดังนั้นข้อมูลจะหายเมื่อปิดหรือรีสตาร์ตเซิร์ฟเวอร์

## 5. ข้อจำกัดของเวอร์ชันนี้

- face vector ที่ใช้เป็นการจำลองเพื่อทดสอบแนวคิด ไม่ใช่ face embedding จากโมเดลรู้จำใบหน้าจริง
- ยังไม่ได้เชื่อมฐานข้อมูลถาวร
- ระบบจัดการผู้ใช้ยังเป็นแบบง่ายสำหรับการสาธิต
- ยังไม่มีระบบ audit log แบบเต็มรูปแบบ
- การกำหนดระยะ 50 เมตรเหมาะสำหรับการทดลอง ไม่ควรนำไปใช้เป็นระบบจริงโดยไม่ทดสอบสภาพแวดล้อมก่อน
