# Attendance Verification System

## วิธีรันแบบง่าย (แนะนำ)

**ทุกระบบ:** เปิดเทอร์มินัลในโฟลเดอร์โปรเจกต์แล้วสั่ง

```
cd "C:\Users\Phetf\Downloads\attendance-system_v5\attendance-system"
python run.py

สคริปต์จะตรวจสอบและติดตั้งแพ็กเกจที่จำเป็นให้อัตโนมัติ จากนั้นเปิดเว็บที่ http://127.0.0.1:8000
(ต้องมี Python 3.10+ ติดตั้งในเครื่อง และตอนติดตั้งบน Windows ให้ติ๊ก "Add Python to PATH")


## หน้าเว็บที่พร้อมใช้งาน

- **นักศึกษา:** `http://localhost:8000/student`
- **อาจารย์:** `http://localhost:8000/teacher`
- **ผู้ดูแลระบบ:** `http://localhost:8000/admin`
- **เอกสาร API:** `http://localhost:8000/docs`

หน้าเว็บใช้ Tailwind CSS และไอคอนผ่าน CDN ต้องเชื่อมต่ออินเทอร์เน็ตเมื่อเปิดใช้งาน
ฟังก์ชัน GPS และกล้องต้องได้รับอนุญาตจากผู้ใช้ และควรเปิดผ่าน `localhost` หรือ HTTPS

##
- **ล็อกอิน**: `/login` ใส่รหัสนักศึกษา + สแกนใบหน้า (ครั้งแรกให้กด "ลงทะเบียนใหม่")
- **หน้าชั้นเรียน**: `/student/classes/{id}` ดูข้อมูลคลาส สถานะรอบ ประวัติการเข้าเรียน และเช็กชื่อ (GPS + ใบหน้า) ภายในหน้านี้
- **ผู้ดูแล**: `/admin/login` กรอกรหัสแอดมิน ค่าเริ่มต้น `ADMIN-2026` — ควรเปลี่ยนด้วยตัวแปรสภาพแวดล้อม `ADMIN_CODE` ก่อนใช้งานจริง เช่น `ADMIN_CODE=รหัสลับ uvicorn src.app:app`
- ผู้ดูแลเพิ่มรหัสอาจารย์ใหม่หรือถอนสิทธิ์ได้ในหน้า `/admin`
- **อาจารย์**: `/teacher/classes/{id}` กด "ยืนยันตำแหน่งและเปิดรอบ" ระบบใช้ GPS ของอาจารย์ ณ ตอนเปิดรอบเป็นจุดศูนย์กลางรัศมี 50 เมตร พร้อมดูรายชื่อ/ประวัติ
- คลาสตัวอย่าง: `MATH101`
- **อาจารย์**: `/teacher/login` กรอกรหัสประจำตัวอาจารย์ (ตัวอย่าง: `T001`) ต้องล็อกอินก่อนสร้างคลาสหรือเปิด/ปิดรอบเช็กชื่อ
- คลาสตัวอย่าง: `MATH101`
- หมายเหตุ: ข้อมูลเก็บในหน่วยความจำ (หายเมื่อรีสตาร์ต) และเวกเตอร์ใบหน้าเป็นแบบง่ายสำหรับเดโม ควรใช้โมเดลรู้จำใบหน้าจริงและฐานข้อมูลก่อนใช้งานจริง
