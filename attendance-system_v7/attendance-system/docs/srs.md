# Software Requirements Specification (SRS)

## 1. วัตถุประสงค์
ระบบบันทึกเวลาเรียนที่ป้องกันการเช็กชื่อแทนกัน (Buddy Punching) โดยตรวจสอบเงื่อนไขความถูกต้อง 3 ด้านพร้อมกัน: ช่วงเวลาที่เปิด, ตำแหน่งพิกัดทางภูมิศาสตร์ (GPS), และข้อมูลชีวมิติทางใบหน้า (Face Recognition)

## 2. บทบาทและหน้าที่ (User Roles)
1. **ผู้ดูแลระบบ (Admin)**
   - จัดการบัญชีผู้ใช้ (เพิ่ม/ระงับ/รีเซ็ตรหัสผ่าน)
   - กำหนดสิทธิ์บทบาทของอาจารย์และนักศึกษา
   - ดูแลข้อมูลส่วนกลางและตรวจสอบประวัติการใช้งาน (Audit Logs)

2. **อาจารย์ (Teacher)**
   - สร้างและจัดการรายวิชา/ห้องเรียน
   - กดปุ่มเปิดรอบเช็กชื่อ (ส่งพิกัด GPS ของอุปกรณ์ และกำหนดเวลาหมดอายุรอบ)
   - ดูรายงานการเข้าเรียนแบบเรียลไทม์
   - ตรวจสอบและอนุมัติกรณีพิเศษ (Manual Override) พร้อมบันทึกเหตุผลกำกับ

3. **นักศึกษา (Student)**
   - ลงทะเบียนบัญชี บันทึกรหัสนักศึกษา และถ่ายภาพใบหน้าเพื่อแปลงเป็นเวกเตอร์ต้นแบบ
   - กดปุ่มเช็กชื่อผ่านเว็บแอปบนอุปกรณ์มือถือ
   - ตรวจสอบประวัติการเข้าเรียนและสาเหตุหากเช็กชื่อไม่สำเร็จ

## 3. เงื่อนไขการเช็กชื่อ (3-Factor Verification)
- **เงื่อนไขที่ 1 (Time Check):** ต้องอยู่ในช่วงเวลาที่อาจารย์เปิดให้เช็กชื่อ (เช่น 15 นาทีแรกของคาบ)
- **เงื่อนไขที่ 2 (Location Check):** ระยะห่างทางภูมิศาสตร์ระหว่างตำแหน่งอาจารย์และนักศึกษาต้องไม่เกิน 50 เมตร (วัดด้วยสูตร Haversine)
- **เงื่อนไขที่ 3 (Face Biometric Check):** ผลการเปรียบเทียบเวกเตอร์ใบหน้า (Euclidean Distance) ต้องผ่านเกณฑ์ความคล้ายคลึงที่กำหนด
